# Time, Not Height: Measuring the Flight-Time Ratio of a Bouncing Ping-Pong Ball

This repository contains experimental data, Python analysis scripts, and a custom phyphox experiment for investigating the successive bounces of a ping-pong ball using smartphone audio recordings.

The project explores how the time intervals between successive impacts can be used to estimate an **apparent coefficient of restitution**, and how the measured ratio depends on release height and the limitations of the physical model.

## Experimental method

A regulation-size 40-mm table-tennis ball is released onto a hard surface. A smartphone records the sounds generated by successive impacts. The audio signal is analyzed to identify impact times and calculate the intervals between consecutive impacts.

Let \(t_n\) denote the time of the \(n\)-th impact. The interval between successive impacts is


\Delta t_n=t_{n+1}-t_n.


Under the idealized assumption of vertical motion under gravity, with negligible air resistance and equal launch and landing levels, the upward launch speed following an impact can be estimated from the corresponding flight time:


u_n\approx\frac{g\Delta t_n}{2}.


A flight-time ratio can then be defined as


r_n^{\mathrm{app}}=\frac{\Delta t_n}{\Delta t_{n-1}}.


This ratio is an **apparent restitution ratio inferred from flight times**, not necessarily a direct measurement of the material coefficient of restitution. Air resistance, acoustic event-detection uncertainty, and other experimental effects may influence the result.

## Getting started

### 1. Download the repository

Clone the repository using Git:

```bash
git clone https://github.com/klyangBUAS/Bouncing-Ball-s-Flight-Time-Ratio.git
cd Bouncing-Ball-s-Flight-Time-Ratio
```

Alternatively, select **Code → Download ZIP** on the GitHub repository page and extract the archive.

### 2. Install Python dependencies

Python 3 is required. Install the packages used by the analysis scripts:

```bash
pip install numpy pandas matplotlib scipy openpyxl
```

### 3. Run the custom phyphox experiment

1. Install phyphox on a compatible smartphone.
2. Import the custom experiment provided in `Original Audio_Phyphox.zip`, following the import options supported by your phyphox version.
3. Open the imported experiment and check that the raw audio signal is being recorded.
4. Place the smartphone on a stable surface near the ball's landing point.
5. Release the ball from the selected height and record its successive impacts.
6. Export the recorded data in Excel format for analysis.

The supplied `experiment-qr.png` provides an additional access method for the experiment. The QR code's availability and behavior depend on the linked experiment resource.

### 4. Organize the recordings

Place the Excel recordings in the appropriate height folders:

```text
data/
├── 10cm/
├── 20cm/
├── 30cm/
├── 40cm/
└── 50cm/
```

Keep the original recordings unchanged when possible, so that the analysis can be repeated and checked against the source data.

## Python analysis

### Single-recording analysis

Run:

```bash
python 01_single_recording.py
```

This script is intended for inspecting an individual recording and checking the detected impact events before analyzing a larger dataset.

Check the input filename and output path in the script before running it. The input Excel file must be located where the script expects it to be.

### Batch analysis

Run:

```bash
python 02_batch_recordings.py
```

The batch script is intended to process all eligible Excel recordings in the five release-height folders. Check the input root, output root, and folder names in the script before running it.

The batch workflow makes it possible to apply the same detection procedure to multiple recordings and compare results across release heights.

**Important:** The actual output filenames and directory structure are determined by the current implementation of each Python script. Consult the path settings and output-writing sections of the scripts when reproducing the analysis.

## Interpreting the results

The analysis can be used to investigate several questions:

- How consistently can impact events be identified from raw smartphone audio?
- How do successive flight-time intervals change during a sequence of bounces?
- Does the first apparent restitution ratio vary with release height?
- How do measurement uncertainty and departures from ideal free-flight motion affect the interpretation of the ratio?
- Why might an experimentally inferred ratio differ from a reference value obtained using a standardized rebound test?

The emphasis is on connecting raw experimental evidence to a physical interpretation, rather than treating a computed ratio as an automatically validated material property.

## Reproducibility and limitations

The Python scripts provide a repeatable workflow for processing the supplied recordings. Nevertheless, automated event detection can miss weak late-stage impacts or identify non-impact acoustic peaks. Detection results should therefore be inspected against the waveform and, where necessary, checked manually.

The flight-time model also relies on simplifying assumptions. In particular, air resistance can affect the relationship between flight time and launch speed. Consequently, a ratio inferred from flight intervals should not be equated uncritically with the coefficient of restitution measured by a standardized rebound-height procedure.

For reproducible comparisons, document the release height, recording conditions, sampling frequency, event-detection settings, and any manual corrections applied to the event list.

## Intended use

This repository is intended for physics education and experimental investigation. It supports activities involving smartphone sensing, signal analysis, repeated measurements, model assumptions, and the interpretation of experimental uncertainty.

The scripts and data may also serve as a starting point for extending the analysis to other release heights, balls, surfaces, or event-detection methods.
